# BOB Security Admin

لوحة إدارة مستقلة لموقع BOB Security، مبنية على مبدأ **المسودة أولًا ثم المعاينة ثم النشر بموافقة صريحة**.

## الحالة الحالية

- `index.html`: واجهة عربية أولية لتحرير النصوص والبطاقات وأسماء الصفحات والألوان.
- حفظ المسودة الحالي محلي في متصفح الجهاز باستخدام `localStorage`.
- المعاينة لا تغيّر موقع `bobsecurity.site`.
- لا يوجد حتى الآن ربط بالمستودع `atshpana/bob-security-landing` أو نشر فعلي من هذه اللوحة.

## لماذا لا نضع رمز GitHub في الواجهة؟

هذا المستودع عام حاليًا. أي رمز وصول يوضع داخل JavaScript أو HTML قد يصبح متاحًا للجميع. يجب أن تبقى الرموز في إعدادات خادم موثوق (Azure Function / Static Web Apps API) أو GitHub Actions Secrets، وألا تُرسل إلى المتصفح.

## مراحل الربط الآمن

1. نشر لوحة الإدارة على عنوان منفصل عن الموقع العام.
2. فرض تسجيل الدخول والتحقق على الخادم من هوية حساب GitHub الإداري المصرح له.
3. حفظ المسودات في تخزين خادمي خاص، لا في ملفات HTML العامة.
4. عرض معاينة للمسودة ومقارنة التغييرات مع النسخة المنشورة.
5. جعل النشر عملية منفصلة تتطلب موافقة صريحة، مع تحقق من الملفات المتغيرة فقط.
6. التحقق من نجاح النشر وتوثيق رقم الإصدار وإتاحة التراجع.

## قاعدة أمان

لا تنشر تغييرات إلى الموقع الأصلي من هذه الواجهة قبل اكتمال المصادقة، وتخزين المسودات الآمن، ومراجعة التغييرات، وآلية التراجع. لا تضف أي مفاتيح أو رموز وصول إلى هذا المستودع.
